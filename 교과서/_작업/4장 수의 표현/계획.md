# 4장 수의 표현 계획

엮는 차시: 03-01(1절, 2절), 03-02(3절, 4절, 끝의 되짚기 쪽). 첫 장이 아니므로 들어가며는 없다.

## 장 지도

- 물음: 수를 어떻게 적고, 컴퓨터는 정해진 비트 수 안에서 음수와 뺄셈을 어떻게 다루는가?
- 흐름: 수의 종류와 연산의 성질(1절) → 같은 수를 기수만 바꿔 적는 수 체계와 변환(2절) → 정해진 n비트 안에서 음수를 나타내는 보수(3절) → 보수로 뺄셈을 덧셈으로 하는 계산(4절).
- 장 전체를 꿰는 생각: 자리값 \(b^i\)로 풀어 쓰는 표현. 변환도, 보수의 기준 \(2^n\)도 모두 이 표현에서 나온다.

## 1. 수와 그 성질 (03-01 슬라이드 2~16쪽, 보정본 00:00:29~00:23:01)

### 1-1) 수의 종류
- 자연수: 기수(base) b인 수 체계로 적은 양의 정수 \(n_b\), \(n = a_k b^k + \cdots + a_0 b^0\), \(0 \le a_i &lt; b\), \(a_k \ne 0\). 슬라이드 첨자 10은 b로 고친 것으로 쓴다(판서). '(k: 자리수)'는 느슨하다: k는 맨 윗자리 지수, 숫자는 k+1개. 3장의 기수(cardinality)와 다른 뜻임을 짚는다. 예제 4-1.
- 정수. 유리수: \(b/a\), \(a \ne 0\). 하한항(lowest terms, 기약분수) = 분자와 분모가 서로소(3장에서 정수의 서로소 뜻을 한 번 말함). 소수부(⟦실수⟧ '실수부' → 소수부, 실수부는 복소수의 말)가 유한하거나 반복. 반복하는 까닭(긴 나눗셈의 나머지가 0~a−1뿐)을 보충.
- 무리수: \(\sqrt{2}\). '무작위' 대신 '끝없이 이어지며 되풀이되지 않음'.
- 실수: \(R = Q \cup I\)(슬라이드의 N∪Z∪Q∪I와 같은 집합임을 3장 기호로). 전개식에 음의 지수, 슬라이드의 \(0 &lt; a_i\)는 \(0 \le a_i\)로. 예제 4-5.
- 복소수: \(i^2 = -1\), 실수부와 허수부(b는 실수), 덧셈과 곱셈(곱 기호 ·는 쓰지 않음). 예제 4-6.
- 그림 4-1: 슬라이드 7쪽 포함 관계(원). 3장 그림 3-1과 같은 관계임을 잇는다.

### 1-2) 수의 연산
- 닫힘 성질: 2장의 '닫혀 있다'를 수 체계별로. 표 4-1(슬라이드 8쪽 쪽 그림으로 확인한 값). 0으로 나누기 제외, 무리수 반례 \(\sqrt{2} + (-\sqrt{2}) = 0\), \(\sqrt{2} \times \sqrt{2} = 2\).
- 교환, 결합, 분배법칙(슬라이드 오타 xy+yz → xy+xz), 1장과 3장 법칙과 같은 이름. 덧셈은 곱셈에 분배되지 않음(1장 경계와 연결). 항등원(identity element), 역(역원, inverse). 0은 곱의 역이 없고, 정수에서 곱의 역이 정수인 것은 ±1뿐 → 나눗셈에 닫혀 있지 않은 까닭과 연결. 예제 4-7.
- Σ(시그마), Π(파이), 색인(index). 작은 예: \(\sum_{i=1}^{4} i = 10\), \(\prod_{i=1}^{4} i = 24\). 1-1의 자리 전개를 Σ로 다시 씀.
- d|n: 'd는 n을 나눈다', d ≠ 0, n = dq. 명제이지 수가 아님(d/n과 구분). 몫(quotient), 약수(divisor), 인수(factor), 배수(multiple). 강의의 피제수, 제수. 2장 짝수 = 2|n. 규칙 넷의 증명(2장 직접증명법), 추이 규칙은 3장 포함관계 (4)와 같은 꼴. d|0.
- n mod d: n = dq + r, 0 ≤ r < d. 슬라이드 'quotation' → quotient. 이 자리의 d는 약수가 아니라 나누는 수. n mod d = 0 ⇔ d|n. 음수 −7 mod 3 = 2.

## 2. 수 체계 (03-01 슬라이드 17~23쪽, 03-02 13쪽, 보정본 03-01 00:23:01~끝, 03-02 01:00:32~01:05:25)
- 10진수, 2진수, 8진수, 16진수(영어 이름 슬라이드대로). 10, 2, 16이 주로 쓰이는 까닭. 2진수는 자리마다 읽는다('1 0 1'). 표 4-2: 0~16을 네 수 체계로(보강, 묶어 바꾸기의 바탕).
- 예제 4-15(⟦판서⟧ 마지막 지수 −3). 10진수 값 155.992919921875.

### 2-1) 수 체계별 사칙연산
- 예제 4-17은 슬라이드 문제(1101×11). 덧셈 올림, 뺄셈 빌림(2를 빌려 옴), 곱셈 부분곱, 나눗셈. 결과를 10진수로 확인(5+3, 4−3, 13×3, 22=5×4+2).
- 예제 4-19: 16을 넘으면 올리고, 빌릴 때 16. 강의의 암산 요령(16에서 먼저 빼고 더하기). 곱셈 7992, 2886, 나눗셈 몫 31 나머지 35.

### 2-2) 수 체계의 변환
- 10진수 → 2진수: 정수부는 2로 거듭 나눠 나머지를 아래(최상위)에서 위(최하위)로, 왜 그런지(163 = 2×81 + 1, 나머지 = 163 mod 2). 소수부는 2를 거듭 곱해 정수부를 위에서 아래로, 왜 그런지. 예제 4-20, 예제(14.75). 보강: 0.1은 2진수로 끝나지 않음.
- 2진수 → 8진수, 16진수: 3자리, 4자리씩(2³=8, 2⁴=16), 정수부는 왼쪽에, 소수부는 오른쪽에 0 채움(0.111 ≠ 0.0111). 예제 4-20 이어서.
- 거꾸로: 자리값으로 풀어 더함. A3.E₁₆ = 163.875.

## 3. 보수의 표현 (03-02 슬라이드 1~9, 15쪽, 보정본 00:00~00:40, 01:11:54~끝)
- 보수의 뜻: 3에 대한 7의 보수 4. 1의 보수(1's complement): 자리마다 더해 1(n비트 전체로 \(2^n - 1\)), 2의 보수(2's complement): 1의 보수 + 1, 더하면 \(2^n\). 이름은 기수 r에 대한 r의 보수와 r−1의 보수에서 옴. 10진수의 9의 보수, 10의 보수와 짝. 3장 여집합(complement)과 같은 영어 낱말, 채우고 남은 부분이라는 뜻. 2의 보수 요령(최하위부터 첫 1까지 그대로, 나머지 뒤집기)과 까닭. 보수는 자리 수에 따라 달라짐.

### 3-1) 컴퓨터에서의 데이터 표현
- 부호화-절대치 표현(sign-magnitude), 최상위 비트(MSB), 최하위 비트(LSB), 부호 비트, 절대치 비트. 그림 4-2(비트 배치와 ±53). 예제 4-28.
- 1의 보수 표현, 2의 보수 표현: 공통점, 차이점(슬라이드 4쪽). 양수는 셋이 같다. 예제(+53, −53). 부호 비트 두고 절대치 비트를 뒤집는 것 = 8비트 전체를 뒤집는 것(표현 사이 연결).
- 데이터의 범위(1): n비트 범위, 왜 \(2^{n-1}-1\)인가(111 = 1000 − 1). 표 4-3: 4비트 16개 코드와 세 표현의 값(다시 계산). −0과 −8.
- 데이터의 범위(2): 초과(overflow) 정의와 드러나는 두 모습. 부호가 다른 두 수의 덧셈은 초과하지 않음. 예 ① 4+5(진짜 초과), ② (−3)+(−4): 참값 −7은 범위 안(1111)인데도 틀림 → 부호화-절대치 비트열을 그냥 더할 수 없음(3-2 한계로 연결). ⟦실수⟧ 4+6 → 4+5.

### 3-2) 보수 표현을 사용하는 이유
- 한계 셋(슬라이드 8쪽). 1의 보수의 '연산의 정확성'은 순환 자리올림이 필요하다는 뜻(4절).
- 뺄셈을 덧셈으로: 컴퓨터는 덧셈 회로 하나로, 보수 만들기는 비트 뒤집기라 간단. 그림 4-3: 10칸 막대(5 − 3 = 5 + 7 − 10, ⟦실수⟧ 3 + 7 = 10). \(x - y = x + (10 - y) - 10\). 기수와 보수가 짝이어야 함(10진수와 10의 보수, 2진수와 2의 보수), 9의 보수는 하나 모자람 → 비유가 끊기는 곳.

### 3-3) 보수의 10진수 변환
- 방법 ①: \(-(2^{n-1}-1)\) 또는 \(-2^{n-1}\) + 절대치 비트 값(기준점에서 떨어진 거리, offset). 표 4-3으로 −7(1000)부터 한 칸씩. 일반식 확인(대수). 양수는 그냥 읽음.
- 방법 ②: 보수를 다시 보수로(¬¬p ≡ p처럼). 예제(1010, 1011 → −5). 2의 보수 1000은 ①로.

## 4. 보수의 연산 (03-02 슬라이드 10~12, 14쪽, 보정본 00:40~00:59:37, 01:05:25~01:11:54)
- 예제 ①(2−4): 자리올림 없음, 결과는 음수의 보수 꼴, 3-3 방법 ②로 읽음.
- 예제 ②(4−2): 자리올림 생김. 2의 보수는 버림, 1의 보수는 다시 더함(순환 자리올림). 10진수로 까닭: 10의 보수 8 → 12, 10 버림. 9의 보수 7 → 11, 10 버리고 1 더함. 식으로 \(x + (2^n - y) - 2^n\), \(x + (2^n - 1 - y) - 2^n + 1\).
- 예제 ③(−2−4): 두 음수, 자리올림 처리 같음.
- 자리올림과 초과는 다름. 2의 보수의 초과 예: 0101+0100 = 1001(−7), 1011+1100 → 0111(7). 3-1의 두 모습이 여기서 그대로 판별법.
- 표 4-4: 세 표현 비교(음수 만들기, 4비트 범위, 0의 표현, 덧셈 뒤 자리올림 처리).

## 장을 마치며
- 자리값 전개가 장을 꿴다: 변환은 같은 수를 다른 기수의 자리값으로 다시 나누는 일, 나머지 연산이 변환의 나머지와 같다, 보수의 기준 \(2^n\)은 n비트 밖 첫 자리값. 2의 보수가 컴퓨터의 표준이 된 까닭(0 하나, 자리올림 버림).
- 다음 장(5장 행렬)으로: 수를 하나씩 다루던 것에서 수를 직사각형으로 늘어놓고 한꺼번에 계산하는 행렬로.

## 떠올려 보기(11개)와 짧은 답
1. \(589_{10}\)에서 8의 자리값과 \(a_i\) 번호 → 10¹, \(a_1\).
2. 유리수의 소수가 끝나거나 되풀이되는 까닭 → 나머지 종류가 유한.
3. 무리수가 덧셈, 곱셈에 닫혀 있지 않은 예 → √2 + (−√2), √2 × √2.
4. 복소수 3 + 6i의 허수부 → 6(6i가 아님).
5. 3|12와 3/12의 차이 → 명제(참) 대 수 0.25.
6. −7 mod 3 → 2.
7. 정수부는 나머지를 아래에서 위로, 소수부는 정수부를 위에서 아래로 읽는 까닭.
8. 0.111₂를 16진수로 바꿀 때 오른쪽에 0을 채우는 까닭 → 0.1110 = 0.E.
9. 4비트 2의 보수 범위가 −8부터인 까닭 → 0이 하나라 1000이 남음.
10. 예제 ②의 다섯째 비트는 초과인가 → 자리올림일 뿐 초과 아님.
11. 1의 보수 덧셈에서 자리올림을 다시 더하는 까닭 → 기준이 2ⁿ−1이라 하나 모자람.
12. 4비트 2의 보수 1011의 값을 두 방법으로 → −5.
