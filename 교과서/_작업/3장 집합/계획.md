# 3장 집합 계획

엮는 차시: 02-01(1절, 2절), 02-02(3절), 02-03(4절, 5절). 첫 장이 아니므로 들어가며 없음.

## 표기 결정

- 집합 식은 모두 KaTeX로 쓴다(\(A \cup B\), \(A'\), \(|A|\), 조건제시법). 명제 쪽 식은 1장처럼 유니코드(p ∨ q).
- 부분집합 ⊆, 진부분집합 ⊂로 구분한다(슬라이드). 1장은 고교 표기대로 P ⊂ Q를 부분집합으로 읽었으므로, 2절에서 이 차이를 짚는다.
- 여집합은 \(A'\). \(\bar{A}\)와 \(A^c\)도 쓴다고 처음 한 번 알린다.
- 수 집합 \(N, Z, Q, I, R, C\)는 2장처럼 기울인 대문자. 겹선 글자(ℕ, ℤ)도 쓴다고 한 번 알린다.
- 자연수는 1부터(1장과 같음). 0을 넣는 책도 있으나 0 < x 조건이 있으면 같은 집합이라는 점을 짚는다.
- 집합 식 안의 묶음은 중괄호 대신 대괄호 [ ]를 쓴다. 중괄호는 집합으로 읽히기 때문이다.
- 멱집합 정의의 묶인 변수는 \(X\)로 쓴다(예제 3-23의 B와 겹치지 않게). P(A)가 1장의 명제함수 P(x)와 글자만 같다는 것을 짚는다.
- 곱하기는 ×로 쓴다(가운뎃점 쓰지 않음).

## 장 지도

물음: 대상을 어떻게 한데 모아 다루고, 모은 것끼리 어떻게 계산할까? 흐름: 집합의 정의와 표기, 상등 → 종류와 포함관계 → 연산(합, 교, 차, 대칭차, 여, 곱, 멱) → 대수법칙(1장 동치법칙과 짝) → 분할. 모든 정의가 '원소 x가 집합에 속한다'는 명제와 1장의 연산자로 쓰인다는 점이 실마리.

## 1. 집합의 개념 (02-01 슬라이드 2~5쪽, 보정본 00:00~17:15)

- 정의: 명확한 기준, 공통 성질, 중복 없음. 보강: 기준이 모호한 모임(큰 수의 모임)은 집합이 아님. 나열 순서는 상관없고 같은 원소를 두 번 써도 하나(중복 없음의 뜻).
- 표기: 원소나열법(줄임표), 조건제시법(세로선 읽는 법은 1장에서 했으니 짧게). 언제 어느 쪽이 좋은지(강의).
- 수 집합 기호와 포함 관계 → 그림 3-1(중첩 그림). 유리수 정의 b/a(a ≠ 0) 보강. 복소수 = 실수 ∪ 허수.
- ∈, ∉ 읽는 법. 2장에서 잠깐 쓴 ∈를 정식으로.
- 기수 |A|. 예제 3-5: 판서로 -4~4 나열(-2, -1 포함). B는 두 유리수 사이에 늘 또 유리수(평균)가 있어 무한. C는 1³=1<2<8=2³, 음수 세제곱은 음수 → 원소 없음(2절 공집합 예고).
- 유한집합, 무한집합.
- 상등: ⟦실수⟧ 두 곳 → 정확한 정의 \(A = B \iff \forall x\,(x \in A \leftrightarrow x \in B)\). 함정: 공통 원소가 하나 있다고 같지 않음({1,2}, {1,3}), 기수가 같다고 같지 않음({1,2,3}, {4,5,6}). 판서 예 A={1,2,3}, B={x | x는 3 이하의 자연수}. 동치와의 연결(명제에서 진릿값이 늘 같음 ↔ 집합에서 원소가 모두 같음). 판서(원을 옮겨 겹치기)는 말로만.
- 예제 3-8: ⟦실수⟧ k ≥ 0이므로 k=0부터 → 1 포함. 답 A=E, B=C, D=F.

## 2. 집합의 종류 (슬라이드 6~10쪽, 보정본 17:15~끝)

- 전체집합 U(1장의 진리집합 이야기에서 이미 씀). 공집합 ∅, { }. 판서: ∅와 {∅}는 다름(|{∅}| = 1). 함정으로 짚는다.
- 부분집합 ⊆: x∈A → x∈B가 모든 x에 대해 참. 진부분집합 ⊂: ⊆이고 ≠. 기수 비교는 유한집합일 때로 한정(보강: N ⊂ Z는 둘 다 무한). ⊇, ⊈ 읽는 법. 1장 ⊂ 표기 차이.
- 판서 그림: 부분집합의 두 경우(A가 B 안, A=B) → 그림 3-2.
- 포함관계 정리 다섯:
  1. A ⊆ A: x∈A → x∈A는 p → p, 늘 참.
  2. ∅ ⊆ A: x∈∅가 늘 거짓 → 함축은 늘 참. 비와 우산, 판서 진리표 → 표 3-1(p → q, 셋째와 넷째 줄 표시).
  3. A ⊆ U.
  4. 추이: ⟦실수⟧ 가설적 삼단논법은 1장 논리적 추론 법칙(동치법칙 아님). 원소는 x로.
  5. A = B ⇔ (A ⊆ B ∧ B ⊆ A): 슬라이드 증명이 느슨함 → (x∈A→x∈B) ∧ (x∈B→x∈A) ≡ x∈A ↔ x∈B(1장 표 1-7 동치)로 쓴다. 두 집합이 같음을 보이는 표준 방법(4절 예제 3-24에서 씀).
  - "당연한 것을 굳이 증명하는 까닭": 직관 대신 정의와 논리로 확인.
- 예제 3-10: 진부분집합 넷과 A ⊂ E, C와 D는 서로 포함 안 함(공통 원소 x 하나, 각자 다른 원소). 기호 ⊈, ⊉.
- 예제 3-11: 원소가 집합인 집합. {a,b} ∈ A(⊆ 아님, a ∉ A), c ∈ A, {d} ∈ A이고 {{d}} ⊂ A, d ∉ A. |A| = 3.

## 3. 집합의 연산 (02-02 슬라이드, 보정본 전체)

### 3-1) 합집합과 교집합
- 합집합 ⟦실수⟧(처음 말한 정의는 교집합) → 바른 정의. 교집합. ∪↔∨, ∩↔∧ 모양 연결. 읽는 법.
- 서로소. 그림 3-3: 합집합, 교집합, 서로소 세 칸 한 줄.
- 예제 3-12(겹친 원소는 한 번), 3-13. 괄호 없이 A∪B∪C를 쓰는 근거는 4절 결합법칙.
- 기수(1): 두 번 센 ①을 한 번 뺌 → 그림 3-4(두 칸). 이항으로 교집합 식. 서로소 줄 ⟦판서⟧ 고침: A∩B=∅이면 |A∩B| = 0이고 |A∪B| = |A| + |B|. 다른 이름: 포함배제의 원리.
- 기수(2): 영역 ①~⑦(⑤⑥⑦은 판서로 더한 것) → 그림 3-5, 영역마다 몇 번 세는지 표 3-2.
- 예제 3-15: 7+8−3=12, |A∩C|=0(공식으로도 7+4−11=0), 14.

### 3-2) 그 외의 집합 연산
- 차집합: B에만 있는 원소는 뺄 것이 없음(강의 비유 "남의 밭"은 뜻만). A−B ≠ B−A. 예제 3-18 ⟦실수⟧ A는 a~j. B−A도 구해 둠(3-19에 씀). 그림 3-6(차, 대칭차 두 칸).
- 대칭차집합: 슬라이드 식은 집합 사이에 ∨를 쓴 느슨한 꼴 → ∪로. x∈A⊕B ⇔ (x∈A) ⊕ (x∈B). 예제 3-19.
- 여집합(보집합): U에 따라 달라짐. 예제 3-20: X는 U=R, Y는 U=C로 보고 구함을 밝힘. 판서 수직선 → 그림 3-7. ⟦실수⟧ −33.
- 차집합을 여집합으로: X − Y = X ∩ Y'(02-03 판서를 제자리로). 4절 예제에서 씀.
- 곱집합: 순서쌍, 순서쌍의 상등(보강). 예제 3-21 ⟦실수⟧ A×B ≠ B×A, 기수만 같음. 판서(선 긋기) → 표 3-3 격자(행 A, 열 B). 행렬 곱 비유는 뺀다(정확하지 않음).
- 멱집합: 정의, 2ⁿ인 까닭(원소마다 넣거나 빼거나) → 2장 예제 2-42 비트 나열과 연결, 표 3-4(부분집합과 비트). 예제 3-23: B의 원소는 ∅와 {∅}, ∅ ∈ B이면서 ∅ ⊆ B.

## 4. 집합의 대수법칙 (02-03 슬라이드 2~5쪽, 보정본 00:00~31:58)

- 표 3-5 대수법칙(쌍대 짝). 1장에서 영어 병기한 이름은 다시 병기하지 않음. 보법칙, 이중 보법칙은 새 이름이라 병기.
- 왜 1장과 같은가: x∈A∪B ⇔ (x∈A) ∨ (x∈B) 등. 표 3-6 대응(∪∨, ∩∧, '¬, U T, ∅ F, 보법칙 부정법칙, 이중 보법칙 이중 부정법칙).
- 곱집합 분배 두 줄은 명제 짝이 없음 → 순서쌍으로 설명.
- 지배법칙 이름 뜻(⟦불명⟧은 U↔T, ∅↔F 대응으로). 분배법칙 꼭 기억(강조). 드모르간: 판서 색칠 → 그림 3-8(A', B', (A∪B)'). "∪와 ∩가 바뀐다"는 요령. 흡수법칙은 1장 그림 1-3이 그대로.
- 예제 3-24: 원소 증명. 슬라이드 끝줄(⇔ A'∧B')을 바르게. ⟦실수⟧ '여집합의 교집합'.
- 예제 3-25: 항등법칙으로 모양 맞추기, 분배법칙 거꾸로. 인수분해 비유의 경계((a+x)(a+y)=a+xy는 산수에서 틀림, 1장 분배법칙 ∨ 쪽과 같은 이유). ⟦실수⟧ U는 ∩로.
- 번호 없는 예제 (A∪B)−(A∩B) = A⊕B: 직관(겹친 곳을 뺀 합집합) 먼저, 줄마다 법칙(빠진 이유 채움, 교환법칙 명시).

## 5. 집합의 분할 (슬라이드 5~6쪽, 보정본 31:58~끝)

- 파이 자르기 비유(판서) → 그림 3-9. 비유의 경계: 빈 조각 없음, 겹침 없음, 남김 없음.
- 정의와 네 성질(번호는 k로 통일). 집합류(블록이라고도).
- 예제 3-30: 다섯 가지. ⟦판서⟧ {a,b,c} ⊆ A(⊂ 아님). 한 덩어리 분할의 (3), (4)는 공집합을 끼워 넣지 말고, k=1이라 (4)의 i≠j 쌍이 없어 저절로 성립(2절 ∅ ⊆ A와 같은 이치)으로 쓴다.
- 분할이 아닌 예 셋(겹침, 모자람, 빈 조각).

## 장을 마치며

집합의 연산과 법칙은 원소가 속하는지를 묻는 명제에 1장의 연산자를 쓴 것. 상등은 두 포함으로. 다음 장은 수의 표현. 곱집합은 6장 관계, 분할은 6장 동치관계에서 다시 쓰임.
