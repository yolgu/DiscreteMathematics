 최단경로문제(Shortest Path Problem)
   ▪ |E|>0인 그래프 G=(V, E)에서 꼭짓점 v1, v2∈V

      간의 가장 짧은 거리의 경로를 찾는 문제
       -출발점(Source): 경로의 시작점
       -도착점(Destination): 경로의 목적지

   ▪ D[vi] : 시작점 v1에서 각 꼭짓점 vi까지 최단경로
     S(탐색 전 최단경로 집합)={v1}
     V(남은 꼭짓점)={v2, v3, …, vn}
     C[vi, vj]=Cvivj : 꼭짓점 vi로부터 vj까지 거리
      -C[vi, vi]=0, C[vi, vj]=∞(경로가 없을 때)

5-1) 최단경로 문제-3

 Dijkstra Algorithm
     D[vi]: 시작점 v1로부터 각 꼭짓점 vi의 최단경로
     C[vi, vi]=0, C[vi, vj]=∞(경로 없을 때), C[vi, vj]=Cvivj

       void Dijkstra( ) {
          S={v1};
          V={v2, v3, …, vn};
          for (i=2; i<=n; i++) D[vi]=C[v1, vi];
          for (i=1; i<=n-1; i++) {
             D[vm]이 최소면 V-S에서 vm 선택; vm을 S에 추가;
             for (V-S에 포함된 모든 꼭짓점)
                D[vn]=min(D[vn], D[vm]+C[vm, vn]);
          }

       }

5-2) 깊이 우선 탐색-1

 깊이 우선 탐색(DFS: Depth First Search)
  ① 시작점 v를 탐색한다.
  ② 꼭짓점 v에 인접한 꼭짓점들 중 탐색되지 않은
     꼭짓점 vsub를 탐색한다.
  ③ 꼭짓점 vsub를 v로 하여 ②를 반복한다.

   ④ 더 이상 탐색되지 않은 꼭짓점이 없으면 바로

     이전에 탐색한 꼭짓점을 v로 하여 ②와 ③을

      반복한다.
   ⑤ 그래프의 모든 꼭짓점을 탐색할 때까지 ④를

      반복한다.

5-3) 너비 우선 탐색-1

 너비 우선 탐색(BFS: Breath First Search)
  ① 시작점 v를 탐색한다.
  ② 꼭짓점 v에 인접한 꼭짓점들 {vs1, vs2, …, vsm}을

      모두 탐색한다.

  ③ 꼭짓점 vs1을 v로 하여 ②를 반복한다. 마찬가지
     방법으로 나머지 vs2, …, vsm에 대해서도 차례대로

      적용한다.
   ④ 그래프의 모든 꼭짓점을 탐색할 때까지 ③을

      반복한다.
