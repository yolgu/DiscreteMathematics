1. 행렬의 개념

 행렬(Matrix) m×n

   ▪ m, n이 자연수일 때 m행(row), n열(column)로
     나열된 실수의 2차원 배열

a11 a12 … a1j … a1n

a21 a22 … a2j … a2n

A= …       …    …  …    …  …    =[aij]
                …       …
      ai1  ai2     aij     ain

………………

am1 am2 … amj … amn

-aij: i번째 행(row 가로줄), j번째 열(column 세로칸)
      (i = 1 : m, j = 1 : n)

2. 행렬 연산의 성질

 행렬 연산의 성질

①A+B=B+A

②A+(B+C)=(A+B)+C ③(AB)C=A(BC)

④A+O=O+A=A     ⑤AI=IA=A

⑥A+(-A)=(-A)+A=O ⑦(-1)A=-A

⑧k(A+B)=kA+kB  ⑨(k+l)A=kA+lA

⑩(kl)A=k(lA)   ⑪k(AB)=(kA)B=A(kB)

⑫A(B+C)=AB+AC ⑬(B+C)A=BA+CA

※ O: 영행렬       I: 단위행렬

3. 행렬의 종류-6

 부울행렬 연산자
   ▪ 크기가 같은 부울행렬 A=[aij]와 B=[bij]에 대해
     1) 합(join): A∨B=[aij∨bij]
     2) 교차(meet): A∧B=[aij∧bij]
   ▪ 부울행렬 (m×p) A=[aij]와 (p×n) B=[bij]에 대해
     3) 부울곱(boolean product): (m×n) A⊙B=[cij]

         a11 a12 … a1p b11 b12 … b1n c11 c12 … c1n
         a21 a22 … a2p ⊙ b21 b22 … b2n = c21 c22 … c2n

           … … …… ………… …………

         am1 am2 … amp bp1 bp2 … bpn cm1 cm2 … cmn

           cij=(ai1∧b1j)∨(ai2∧b2j)∨…∨(aip∧bpj)

3. 행렬의 종류-9

 부울행렬 연산의 특징

1) A∨A=A,  A∧A=A

2) A∨B=B∨A, A∧B=B∧A

3) (A∨B)∨C=A∨(B∨C), (A∧B)∧C=A∧(B∧C)

(A⊙B)⊙C=A⊙(B⊙C)

4) A∨(B∧C)=(A∨B)∧(A∨C),

A∧(B∨C)=(A∧B)∨(A∧C)
