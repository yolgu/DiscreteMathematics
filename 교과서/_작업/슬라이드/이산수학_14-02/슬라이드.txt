3-3) 탐색 알고리즘-3

▪ 순차 탐색 알고리즘

1 algorithm sSearch(int a[], int key, int n){

2 int i;

3 for i=0 to n-1

4   if a[i]==key then return i;

5   endif

6 next i

7 return -1;

8}

-시간복잡도: 평균 횟수=(1+2+…+n)/n=(n+1)/2
 f(n)=(n+1)/2≤(n+n)/2=n ∴ f(n)=O(n)

3-3) 탐색 알고리즘-4

▪ 이진 탐색 알고리즘

1 algorithm bSearch(int a[], int key, int n){

2 int left=0, right=n-1, mid;

3 while (left<=right)

4     mid=(left+right)/2;

5     if a[mid]<key then left=mid+1;

6     elseif a[mid]>key then right=mid-1;

7                      else return mid;

8     endif

9 endwhile

10 return -1;

11 }
